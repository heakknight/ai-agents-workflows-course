# Browser AI workflow

A private, browser-only document summarizer built with Vite, TypeScript, LiteParse, and Gemma 4. PDF, TXT, and Markdown processing stays in the browser and works best in a WebGPU-capable Chromium browser.

## Run

```bash
npm ci
npm run dev
```

Open the shown local URL. Run `npm test` for policy tests or `npm run build` for a full type/build check.
