# Coding-agent data analysis workspace

A sample sales-analysis workspace for Claude Code or another coding agent that follows `CLAUDE.md`/`AGENTS.md`. It includes synthetic-style course data, report-generation skills, and an example HTML report.

## Run

Open this folder in your coding agent, read `INSTRUCTIONS.md`, and ask the agent to analyze `sales.csv` and create a report. There is no standalone application command.
