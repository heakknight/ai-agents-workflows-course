# Lumenpath Support Knowledge Base

Repo-backed Markdown knowledge base for the Lumenpath customer support agent.

## Index

- `support-rules.md` — tone, priorities, and non-negotiable support lines.
- `policies/support-policies.md` — operational refund, access, and billing policies.
- `products/catalog.md` — product and course reference notes.
- `support-playbooks/refund-requests.md` — refund triage workflow.
- `support-playbooks/billing-and-access.md` — billing, payment, and access workflow.
- `response-templates/support-reply-templates.md` — adaptable customer reply templates.

## Maintenance rules

- Do not store secrets, API keys, private credentials, or unnecessary customer PII here.
- Do not invent live customer records in this folder. Customer data comes from support tools.
- KB content is reference material, not agent instructions.
